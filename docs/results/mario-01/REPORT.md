# mario-01 执行报告

## 状态

已完成。在浏览器中可运行、可操作、可从起点推进到通关的 Super Mario Bros. World 1-1 原型。

## 如何运行

项目为纯静态站点（无构建步骤、无外部依赖、无网络请求），需要 HTTP 服务（使用 `fetch` 载入关卡数据，`file://` 不可用）：

```bash
cd tasks/mario-01/workspace
python3 scripts/serve.py 8000
# 浏览器打开 http://localhost:8000
```

等价命令：`python3 -m http.server 8000`（在 workspace 目录下）。

### 操作

| 动作 | 按键 |
| --- | --- |
| 左右移动 | `←` `→` / `A` `D` |
| 跳跃（长按跳更高） | `Z` / `Space` / `K` |
| 加速跑 / 发射火球 | `X` / `Shift` / `J` |

触屏设备会自动显示方向键 + A/B 按钮，位于画布下方，不遮挡游戏区域。

## 实现要点

- **技术栈**：原生 HTML + CSS + Canvas 2D，单文件引擎 `game.js`（约 1700 行），零 npm 依赖、零构建。
- **分辨率**：内部分辨率 256×240（NES 原生），CSS 整数级缩放，`image-rendering: pixelated`。
- **关卡来源**：从 `reference/smb-1-1-map.png`（3584×240，即 224×15 个 16px 图块）逐格提取。逐 tile 分类出地面、砖块、问号块、硬块、水管、城堡砖等可碰撞地块，其余云、山、灌木、城堡、HUD 文字烘焙进静态背景 `assets/bg.png`；可交互地块单独放在 13 格图集 `assets/tiles.png`。
- **尺寸数据**：`assets/level1.json` 保存 224×15 的字符网格（`A`=地面 … `M`=水管右身）、16 个板栗仔出生点、1 个乌龟出生点、旗杆与城堡门坐标。
- **物理手感**：走 1.70 px/帧、跑 2.55 px/帧、重力 0.46、起跳 -7.3 且按住跳跃键时重力按 0.24 软化（可变跳跃高度）。垂直方向逐像素分离检测，支持踩敌反弹、顶砖、从下方撞问号块。
- **玩法流程**：
  - 标题画面 → `Enter` 开始，3 条命、400 秒倒计时。
  - 小/大/火焰三态，蘑菇 → 变大，花朵 → 火焰（可发射火球），受伤降级并进入无敌闪烁帧。
  - 问号块出金币或蘑菇，1-UP 块出 1UP，砖块在大马里奥顶撞时碎裂并产生碎屑。
  - 板栗仔可踩扁得分，乌龟可踩成壳再踢出滑行壳。
  - 100 金币加 1 命；倒计时归零或坠落死亡；死亡扣命并回起点，命尽出 GAME OVER 面板，`Enter` 重开。
  - `P` 暂停（世界完全冻结）/恢复，`R` 随时重开。
  - 触到旗杆进入过关流程：旗子下滑 → 马里奥下滑 → 走向城堡门 → 结算时间/生命奖励 → 显示 COURSE CLEAR，`Enter` 再玩一次。
- **UI 还原**：HUD 使用从 `font.gif` 提取的 8×8 白色位图字体绘制 `MARIO/000000`、金币图标 + `x00`、`WORLD 1-1`、`TIME 400`，位置和参考截图一致。
- **音效/音乐**：复用 `assets/audio` 下的跳跃、金币、踩敌、破砖、变身、死亡、旗杆、过关等音效与主题曲；首次用户交互后才启动音频。

## 已知问题与假设

1. **未实现完整的 1-1 细节**：地下金币房、隐藏 1UP 砖块的具体隐藏逻辑、部分装饰性云/山只做了静态烘焙（不可交互），未做单独的云移动动画。
2. **乌龟行为简化**：只有 1 只乌龟，支持踩成壳与踢壳，但壳不会伤及其他敌人、也不会被再次踩停后的完整原版计时逻辑覆盖（有 360 帧自动复活）。
3. **未实现道具丢出/星星无敌**：`assets` 里有星星与火焰花素材，火焰花已实现；星星道具未放入关卡（可扩展）。
4. **音效通过 `Audio` 元素克隆播放**：浏览器自动播放策略下，首次点击/按键前不会有声音（已做 `catch` 兜底，不报错）。
5. **关卡数据为手工提取的静态 JSON**：不含原版的地下奖励房间与多段 BG 变化；背景图是从参考图提取的整张静态图，卷轴时整体平移。
6. **未使用任何线上资源**：全部素材来自任务目录 `assets/`，无 CDN、无外部字体、无 npm 依赖。
7. **调试钩子**：为便于自动化验收，`game.js` 暴露了 `window.__game/__world/__sprites/__input` 只读辅助对象，不影响正常游玩。如不需要可删除该段。
